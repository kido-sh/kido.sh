Native speed, zero shims

Unmodified macOS arm64 binaries like sw_vers and uname run natively in under a second, with no rebuilds and no emulator overhead. Runs on Virtualization.framework on macOS, or KVM on ARM64 Linux.

A micro-VM per container

Every container is its own virtual machine. The host talks to the guest agent over a mutually authenticated, encrypted channel.

Isolated networks

User networks cannot reach each other, --network none disables networking, and published ports bind to 127.0.0.1 by default.
